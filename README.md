## 🚀 Features

- **Complete Data Pipeline**: Raw data → Validation → Cleaning → Transformation → Feature Engineering → Analytics
- **RFM Analysis**: 7 customer segments (Champions, Loyal, Potential Loyalists, New, At Risk, Can't Lose, Lost)
- **Customer Churn Prediction**: ML-based churn probability with risk segmentation
- **Data Quality Report**: Automatic quality scoring with recommendations
- **Multiple Output Formats**: CSV, JSON, Excel, HTML, PNG, PDF
- **Dashboard**: Interactive visualizations and insights
- **CI/CD**: Automated testing, linting, and deployment
